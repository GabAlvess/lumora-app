# Assets das telas de acesso

`lumora-plaza.png` é uma ilustração gerada para esta implementação: praça social isométrica, café, jardins e personagens, orientada pela referência visual do projeto. É uma ambientação da interface, não uma captura do jogo ou aprovação final da arte de avatares e cenários.

O build copia a imagem para `dist/images`. Os ícones de marca usados nos botões sociais vêm de Simple Icons, com a licença preservada em `dist/licenses/simple-icons.txt`. Os nomes e marcas continuam pertencendo aos respectivos titulares; sua presença na interface não implementa OAuth nem indica parceria.
